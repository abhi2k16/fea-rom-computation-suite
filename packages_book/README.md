# packages_book

Planning material for the book *Architecting Computational Mechanics: From-Scratch Finite Element Analysis and Reduced-Order Modeling in Python*, based on the two packages of this repository (`fea_engine`, `rom_engine`).

- `plan/` the book plan, written in LaTeX in the same style as `paper/`.
  Build: `cd plan && latexmk -pdf main` (or `pdflatex main && bibtex main && pdflatex main && pdflatex main`).
  `plan/refs.bib` was copied from `paper/refs.bib` and extended with contact and active-set references.
- `book/` the book itself (A4, class `book`). `main.tex` includes `chapters/ch01.tex` ... `ch14.tex` and `appA.tex`; Chapters 1 (architecture), 2 (meshes), 3 (linear continua and elements), 4 (dynamics), 5 (nonlinearity), 6 (batched kernels), 7 (contact), 8 (POD, Galerkin, affine sweeps) and 9 (balanced truncation, Krylov, SOAR) are written, the others are stubs.
  Build: `cd book && latexmk -pdf main`.
  Each chapter ends with `\chapterrefs` (defined in `macros.tex`): its own list of references, numbered from [1] (package `chapterbib`), taken from `book/refs.bib`. The stubs get the line when they are written.
  Figures, tables and the number macros of Chapters 1 to 9 are generated by `book/scripts/ch01_assets.py`, `ch02_assets.py`, `ch03_assets.py`, `ch04_assets.py`, `ch05_assets.py`, `ch06_assets.py`, `ch07_assets.py`, `ch08_assets.py` and `ch09_assets.py` (`ch06_assets.py` also needs `paper/experiments` on the path; it imports the benchmark helpers without running or overwriting the stored paper results) (run from the repository root with `fea_engine` importable; `ch08_assets.py` also needs `rom_engine/src` on the path); `book/tables/author_machine_ch07.tex` holds numbers entered by hand from a run on the author's machine.
