# packages_book

Planning material for the book *Architecting Computational Mechanics: From-Scratch Finite Element Analysis and Reduced-Order Modeling in Python*, based on the two packages of this repository (`fea_engine`, `rom_engine`).

- `plan/` the book plan, written in LaTeX in the same style as `paper/`.
  Build: `cd plan && latexmk -pdf main` (or `pdflatex main && bibtex main && pdflatex main && pdflatex main`).
  `plan/refs.bib` was copied from `paper/refs.bib` and extended with contact and active-set references.
- `book/` the book itself (A4, class `book`). `main.tex` includes `chapters/ch01.tex` ... `ch14.tex` and `appA.tex`; only Chapter 7 (exact unilateral contact) is written, the others are stubs.
  Build: `cd book && latexmk -pdf main`.
  Each chapter ends with `\chapterrefs` (defined in `macros.tex`): its own list of references, numbered from [1] (package `chapterbib`), taken from `book/refs.bib`. The stubs get the line when they are written.
  Figures, tables and the number macros of Chapter 7 are generated by `book/scripts/ch07_assets.py` (run from the repository root with `fea_engine` importable); `book/tables/author_machine_ch07.tex` holds numbers entered by hand from a run on the author's machine.
