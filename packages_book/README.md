# packages_book

Planning material for the book *Implementing Reduced-Order Modeling in Computational Mechanics: Theory, Algorithms, and From-Scratch Implementation in Python*, based on the two packages of this repository (`fea_engine`, `rom_engine`).

- `plan/` the book plan, written in LaTeX in the same style as `paper/`.
  Build: `cd plan && latexmk -pdf main` (or `pdflatex main && bibtex main && pdflatex main && pdflatex main`).
  `plan/refs.bib` was copied from `paper/refs.bib` and extended with contact and active-set references.
- `book/` the book itself (A4, class `book`). `main.tex` includes `chapters/ch01.tex` ... `ch14.tex` and `appA.tex`; Chapters 1 (architecture), 2 (meshes: element topologies, quality, generators, grading, multi-block meshes, parts, node sets, exchange formats with an end-to-end Abaqus import, visualisation, dispatcher; scripts `ch02_assets.py`, `ch02_figs.py` (PyVista figures need `xvfb-run -a` on a machine without a display), `ch02_import_assets.py`, `fea_engine/examples/import_abaqus_mesh_demo.py`), 3 (linear continua and elements), 4 (dynamics), 5 (nonlinearity), 6 (batched kernels, with a section on the optional PyTorch backend; script `ch06_torch_assets.py`, which quotes the author-machine CPU/CUDA records), 7 (contact), 8 (POD, Galerkin, affine sweeps) 9 (balanced truncation, Krylov, SOAR) 10 (frequency-domain ROMs, certified bounds) 11 (substructuring, component reduction) 12 (non-intrusive identification, nonlinear ROMs) 13 (hyper-reduction, contact ROMs) and 14 (verification, nine reproduction studies each with concept, mathematics, geometry and mesh, results and comparison tables, and an integrated parametric pipeline; scripts `ch14_assets.py`, `ch14_geom.py`, `ch14_pipeline.py`) are written, and so is Appendix A (differentiable assembly and autograd tangents; script `appA_assets.py`, which runs without PyTorch). No chapter or appendix is a stub any more. The book is a companion to the git tag `release-fea1.0.1-rom0.2.0`. Front matter has a page on how to read the verification sections; Appendices B (conventions and tolerances), C (notation and glossary) and D (chapter, script and test map) are written.
  Build: `cd book && latexmk -pdf main`.
  Each chapter ends with `\chapterrefs` (defined in `macros.tex`): its own list of references, numbered from [1] (package `chapterbib`), taken from `book/refs.bib`. The stubs get the line when they are written.
  Figures, tables and the number macros of Chapters 1 to 13 are generated by `book/scripts/ch01_assets.py`, `ch02_assets.py`, `ch03_assets.py`, `ch04_assets.py`, `ch05_assets.py`, `ch06_assets.py`, `ch07_assets.py`, `ch08_assets.py`, `ch09_assets.py`, `ch10_assets.py`, `ch11_assets.py`, `ch12_assets.py` and `ch13_assets.py` (`ch06_assets.py` also needs `paper/experiments` on the path; it imports the benchmark helpers without running or overwriting the stored paper results) (run from the repository root with `fea_engine` importable; `ch08_assets.py` to `ch10_assets.py` and `ch12_assets.py` and `ch13_assets.py` also need `rom_engine/src` on the path, and `ch08`/`ch10` need `rom_engine/examples`; `ch12` and `ch13` also need `rom_engine/tests` and `fea_engine/tests`; `ch13` also runs `rom_engine/tests/hyper_reduction_timing.py`); `book/tables/author_machine_ch07.tex` holds numbers entered by hand from a run on the author's machine.
