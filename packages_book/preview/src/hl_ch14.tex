\hlsection{The question}
\begin{hlquote}By now the book has made many numerical claims, and a careful reader should ask how much each one proves. This chapter says what kind of evidence each is, rebuilds nine published studies from the packages alone, failures included, and runs one complete pipeline from mesh to a prediction on loads never seen.\end{hlquote}
\vspace{8pt}\begin{hlsum}\textbf{How much a number proves depends on the kind of evidence, so each claim is placed on a ladder from unit test to integrated run.} The chapter says what each number does not prove, rebuilds nine published studies from the packages alone with failures included, and runs one pipeline from mesh to a prediction on loads never seen. Every error on unseen parameters and loads is below $10^{-3}$ on both meshes, and the reduced solve takes \cplSTRom{} ms against \cplSTFomsparse{} ms for a sparse full-order solve. It is one author on one machine, so these are reproductions, not independent confirmation.\end{hlsum}
\hlsection{Key concepts}
\begin{description}\setlength\itemsep{5pt}\setlength\parsep{0pt}\renewcommand{\descriptionlabel}[1]{\hspace{\labelsep}\sffamily\bfseries\color{hlnavy}#1}
\item[Six levels of evidence] from unit test to integrated run, each answering a different question
\item[Independent reference] never the code under test: closed form, finer model or published number
\item[Reproduction study] a published method rebuilt from its description and compared with the reported numbers
\item[Outcome table] states for each study what agreed, what did not and what was not specified
\item[Integrated pipeline] mesh, system, snapshots, basis and reduced model, queried on unseen parameters and loads
\item[Local quantity] reported next to the global error, with offline, online and lifting cost
\end{description}
