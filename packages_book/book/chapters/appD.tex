\chapter{Chapters, scripts and package tests}\label{ch:map}

Every number, figure and table of a chapter is generated by the script in the second column of \Cref{tab:map}, which writes the files in \texttt{figures/} and \texttt{tables/} of the book and the macros of \texttt{tables/numbers\_chNN.tex}. The third column lists package test files, chosen by file name, that cover the topic of the chapter. The list is a pointer, not a claim of complete coverage: a chapter may use further tests, a test file may cover several chapters, and a passing test shows only what its assertions state (see the reading guide).
