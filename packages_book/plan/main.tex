\begin{abstract}
This document plans a book that uses the two packages of this repository, \fea{} (full-order finite element analysis) and \rom{} (model order reduction), as the running example of how to build a computation engine from scratch. It fixes the audience and scope, records what was changed in the first outline and why, gives the chapter map with the code each chapter explains and the figures, tables and listings that already exist in the repository, states the citation system, the evidence policy and the production plan, and lists the decisions that are still open. Every number quoted here comes from a script, a test or a result file in the repository; items that do not exist yet are marked as such.
\end{abstract}
